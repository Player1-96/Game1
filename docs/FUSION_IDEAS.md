## 一、先立判据（沿用项目既有那条）

> **一条配方 = 一个新的「动词」。说明能用「伤害 +X%」写完的，就是假的。**

判据的第二半（这次新加的）：

> **新动词必须与已有动词「结构上可分」** —— 不是「也是追踪，但更准」，
> 而是「路径形状不一样，一眼看得出」。

---

## 二、现有 25 条占掉的是哪些动词

我把 25 条按「它改了什么」重新分了一遍，结论有点意外：

| 类别 | 条数 | 具体 |
| --- | --- | --- |
| ⭐ **改弹道/攻击方式** | **4** | 乱披风（角度随机）、万剑归宗（出手时各锁一敌）、双生剑（追+折复合）、贯灵梭（穿透递增） |
| 命中后加状态 | 7 | 雷池、冰爆、点燃、毒爆、连锁雷+钉、冰传染、暴击点燃 |
| 击杀/经济 | 5 | 摄魂、回蓝、捡钱回蓝、灵石换钥匙、命中掉钱 |
| 防御 / 护盾 | 5 | 破盾还击、击落补盾、盾上限、斩杀回蓝、受创回血 |
| 移动 / 蓄势 | 2 | 移动攒风刃、钉住→暴击 |
| 世界内部（北欧 4 条） | 4 | 破盾雷环、钉住必暴、斩杀回蓝、受创回血 |

**也就是说：25 条里只有 4 条动的是「怎么打」，其余 21 条都是「打中之后发生什么」。**
弹道拓扑这一整片几乎是空的 —— 这就是下面这批要填的地方。

| A5 | **符文剑阵** | 分影诀（中）× 卢恩石（北） | **弹体之间织网**：同时飞在空中的剑彼此连成符文线，敌人**穿过线**受伤 | 最近的是连锁雷（命中后从敌人跳到敌人）。差别：这是**弹体之间**的静态网 —— 伤害不再来自「打中谁」，而来自「谁撞进了网」 | 大 |

## 五、一条工程结论（决定先做哪几条）

上面 **A1 / A3 / A4 / A6 / B1 / C1 / C2 / C3 八条，全都挂在同一个新钩子上**：

```
Fusion.onBullet(b, g)   // 每帧对每一发友方子弹调一次
```

意思是 —— **先加这一个钩子，族 A 和族 C 的六条就能一次铺完**，不用为每条配方各写一套。
所以从投入产出看，族 A 应该整族一起做，而不是挑一条做。

## 七、顺手发现的两个问题（与这批设计无关，但都该处理）

### 1️⃣ 枢纽件已经过载，「融掉即本局不再掉落」这条惩罚快顶不住了

| 材料 | 已有几条路 |
| --- | --- |
| **引雷符** | **4 条**（雷殛剑 / 霜雷 / 雷火焚天 / 两界雷劫） |
| 玄冰符 / 赤焰符 / 太虚护盾 / 聚灵阵 | 各 3 条 |

配合现行规则（材料喂给融合阵后**本局不再掉落**），玩家拿到引雷符时几乎**不敢融**——
融一条就废掉另外三条，而阵图一层只开一次。

**建议二选一**（我可以直接改）：
- **A**：把「退出本局池」收紧成「**只在已融过的那条路上**失效」—— 即材料照旧掉落，但已融过的配方不再出现在面板里。枢纽件就能放心融了。
- **B**：维持现状，但面板上的警告改成**逐条列出会废掉哪些路**（现在已经列了，可以再加一句「共 N 条路，融掉后剩 M 条」）。

### 2️⃣ 融合产物的「世界」列在资源表里显示是错的

9 件第三批产物（雷神战铠 / 两界雷劫 …）定义里**没有 `world` 字段**，导出时按默认值 `cn` 处理
→ 资源表「法宝」页把它们全标成「中式仙侠」。其中**跨世界的 5 件其实一件一个世界**。
建议按配方材料自动推断：材料同界 → 该界；跨界 → 新增「两界交融」。
