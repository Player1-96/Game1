# 九劫录 · 飞剑问仙

一款**修仙题材**的《以撒的结合》式俯视角 Roguelike 游戏（HTML5 网页版）。
所有美术素材（角色、妖物、Boss、地宫、法宝图标）**均由代码逐像素绘制**，无任何外部图片资源。

## 运行方式

直接双击打开 `index.html` 即可（无需服务器、无需安装依赖）。
推荐使用 Chrome / Edge 浏览器。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 身法移动 |
| `↑` `↓` `←` `→` | 御剑射击（四个方向） |
| 鼠标左键（按住） | 朝准星方向连续射击 |
| `空格` | 施展专属技能。**舞剑流开局即自带**（冷却 **15 秒**）：按住蓄势、松手朝准星突进，蓄势越久突进越远；其余流派首杀精英后获得（冷却 30 秒） |
| `Q` | 施展当前小技能（消耗灵力 + 各自独立的冷却） |
| `1` `2` `3` | 切换当前小技能槽位（最多带 3 个） |
| `E` | 交互：坊市购买 / 祭坛献祭 / Boss 法器二选一认领 |
| `F` | 埋设雷符（1.4 秒后爆破） |
| `R` | 死亡后重入轮回 |
| `M` | 静音开关 |

## 三大流派

开局「择一流派」任选其一（`←` `→` 或 `1` `2` `3` 选择，`Enter` 入门），局内长按 `R` 可换流派重开。

| 流派 | 打法 | 专属技能 |
| --- | --- | --- |
| **飞剑流** | 按住鼠标持续御剑，出手极快、转向灵动，以频次压制 | 万剑归宗 |
| **巨剑流** | 按住蓄力、松手一击破军，段位越高穿透 / 剑宽 / 射程越强 | 天崩剑狱 |
| **舞剑流** | 近战横扫，一刀扫一片，挥砍自带剑气可斩落术法 | 剑影三叠（开局自带） |

**舞剑流**的平A 是朝准星方向的一记弧形挥砍：三帧挥剑动作（起手 / 力劈 / 收势），
刃光跟着剑锋扫出来而不是凭空炸开。伤害按 **1.10 的近战系数**折算 ——
贴脸挨撞是这套流派的常态，单刀得比飞剑的单发重；一次基础最多扫到 **3 只**
（按离剑锋由近及远取，多的要靠「穿云梭」这类加穿透的法宝），挥砍时还有一小段前冲。
剑锋触及约 **46px**，不必把脸贴到妖物身上；**挥砍顺手就斩落周身的敌方术法**
（半径约 52px，不需要法宝）—— 这是舞剑流对弹幕的正面答案。
拿到「**玄元镜**」后更进一步：这件法宝在舞剑流下化名「**照影镜**」，
被斩中的术法**不再湮灭，而是掉头打回去** —— 伤害按玩家伤害 ×1.3 结算。
一、二重是**一记 180° 的原路回敬**（术法从哪来就回哪去，敌人挪了位就打空），
**只有满三重「照影如潮」才会自寻最近的妖物**，那时伤害 ×2.3 且多穿 2 个。
同一件镜子在飞剑 / 巨剑流下仍是「击落术法、范围随镜阶扩大」，
所以它是唯一一件**在三个流派下用途完全不同**的法宝。
专属技「剑影三叠」**开局即自带**（不必等首杀精英；基础冷却 **15 秒**，比另两派的 30 秒短一半），
分三段：

1. **一段** —— 按住空格蓄势，松手朝指针突进斩击，**突进全程无敌**，途中撞到的妖物吃一次伤害。
   **蓄势越久突进越远**：刚够下限就松手是一记约 **74px** 的突进，
   蓄满（**0.4 秒**）则是约 **185px** —— 够横穿大半间石室、直接从尊者身上穿过去；
   突进帧数同步从 11 帧拉到 24 帧，所以短突进的位移小、**无敌时间也短** ——
   用它躲弹幕，还是用它贴脸开连招，得当场掂量。
   蓄势时头顶槽里那道竖刻度就是「能不能放出」的下限，地上还会沿指针点出一串落点预览；
   不到下限的点按（低于 0.05 秒）算误触：收势、不位移、也不收冷却；
   突进中途撞上墙会**当场收势**，不会贴着墙滑完整个无敌时长；
2. **二段** —— 一段**命中**后 1.4 秒内可立即再接一段（靠连段窗口放行，不看冷却），伤害在一段基础上 **+20%**；
3. **三段** —— 二段命中后再接一段，突进落脚即化作**五连斩**（严格五段），
   每段都在二段基础上**必定暴击**。

风险全在这套连招里：**蓄势期间被打断，剑势立刻溃散、技能马上进冷却**；
命中了却没在连段窗口内接招，连招归零、冷却同样回满。所以「敢不敢贴上去」就是这套流派的赌注。

**「剑意不绝」在舞剑流下是击杀返还**：每斩杀一只妖物，专属冷却往回退 **2 / 3 / 4 秒**
（一级 2 秒、二级 3 秒、三级 4 秒，每级落差一致）。这是全表唯一一条**条件触发**的冷却缩减 ——
蓄势被打断、空放、人没杀掉，就一分不返；换来的正是它比「释放时固定扣减」的同名路线
（飞剑流仍是 −2/4/6 秒）强出的那一档。满级时一间五只妖物的石室就足以把 15 秒冷却整个抹平，
所以这条线要的是**一直在杀东西**，而不是站着等冷却走完；它也**不改变名义冷却**
（恒为 15 秒，因此不会因升级跌破 8 秒下限 —— 那条下限只约束「释放时固定扣减」型路线）。
返还发生的那一瞬，HUD 专属格的冷却条会**缩掉一截**并亮一道青线标出「−N 秒」。

**连招全程斩获的击杀都算数**：冷却自**第一段**释放那一刻起算，二段、三段既不重置也不清零，
所以三段的突进里斩掉几只，冷却就一路往回退 —— 满级三段各斩一只，收招时冷却只剩零点几秒。
（接下一段靠的是**连段窗口**而不是冷却归零，两者已经解耦。）反过来，全程一只没杀的话，
收招时冷却仍有 13 秒左右 —— 返还不会凭空变多。

法宝在舞剑流下会换一套说法与口径（如「御剑术·三重」变「回风拂柳」，
加的是挥砍弧度而不是分裂柄数），「灵犀玉佩」这类射速法宝则同时加快挥砍与蓄势。

## 玩法（以撒式核心循环）

- **随机地宫**：每一层由 12~20 个房间随机拼接（房间拓扑 + BFS 距离 + 特殊房间规则），
  石室清空妖物后石门自开。
- **特殊洞府**（精英窟 / 密室按概率出现，不是每层都有）：
  - 藏珍阁：石门上锁，需消耗 1 把钥匙（妖物 / 尊者掉落）开启，开箱得随机法宝
  - 坊市：用灵石购买丹药 / 法宝 / 功法
  - 祭坛：献祭气血，赌一把机缘
  - 精英窟：一只精英妖物镇守（越深越常见），灵石产出是普通石室的两三倍
  - 密室：**藏在精英窟的墙里** —— 御剑击之三下、或一记雷符即可破墙入内；
    精英本身不再额外掉法器，回报全在这间密室里
- **动态难度**：按玩家已获法宝折算出的「实力倍数」校正本层妖物的血量与数量。
  第一层保持原样，法宝越多越杂敌人越硬（校正有上限，凹曲线，不会变成加血墙）。
  屏幕右下角以「劫数 缓/平/险/危/绝」标示当前强度。
- **法器二选一**：击败每层魔头后摆出两件法器，站上去会摊开该法宝的效果说明，
  按 `E` 认领其一，另一件当场消散（不会走过去就误拿）
- **雷符**：按 `F` 于脚下埋符，1.4 秒后炸开 —— 重创周围妖物（14 伤害 + 击退）、
  清空范围内弹幕、炸碎石柱与宝箱、轰开裂缝墙；贴脸引爆会自伤半颗心。
- **魔窟 Boss**：每层尽头镇守魔头（血魔尊者 / 白骨夫人，三阶段弹幕），
  斩杀后出现八卦传送阵，踏入即飞升至下一层。共五层，第五层击败魔头即飞升通关。
- **法宝体系**（被动）：穿透、追踪、三重分裂、灼烧、冰冻、引雷连锁、暴击、
  击杀增伤、毒雾、护盾……20 余种，Build 自由组合。
  - **数值型**（伤害 / 射速 / 分裂 …）可以重复获得，效果直接叠加
  - **功能型**（追踪 / 冰封 / 击落术法 / 毒雾 / 摄魂 / 天眼 / 祥云）重复获得即**进阶**：
    名称加「·二重 / ·三重」，描述改为该阶的实际数值提升，满阶后标注「圆满」
- **小技能**（按 `Q` 施展，最多带 3 个，`1`/`2`/`3` 切换）：天雷引 / 缩地成寸 / 五行遁术 / 护体金光，
  另有近战向的**擒龙手**（把射程内的妖物扯到身前 20px 并拍开身前术法）与
  **裂空斩**（朝指针劈出一道贯通剑气，一条线上的妖物一起吃）。
  消耗灵力，且**每个技能各有一份独立冷却**（挂在槽位上，切槽绕不过去，
  否则无敌类技能连放就直接无敌通关了）。重复拾到同一个即升级（上限 5 级，只增强不涨价）。
- **灵力**（蓝条）：**开局没有自然回复**（0 点/秒）——想要涓流回蓝，得去捡法宝**回灵符**
  （每份 +1 点/秒，可叠加）。日常主要靠捡地上的**灵力珠** ——
  斩妖 62% 概率掉一颗（量按妖物体量），精英**必掉**，Boss **每次转阶段**散落 3 颗，
  都得上前去捡。灵力珠是靛蓝菱形宝珠（脉动青晕），灵石是碧绿方孔钱，形状、颜色、拾取音效都不同。
- **心血产出**：平时几乎不掉（2%），**只剩一格血时才明显放水**（24%，剩两格 7%）。
  血量危机要真的会咬人，不能一路满血碾过去。
- **补给逐层收紧**（`LOOT_DECAY = 0.82`）：难度不只会被「敌人变强」拉平，也会被「补给变多」拉平 ——
  后期 build 成型清怪更快、怪数量上来了（数量系数最多 ×1.5）、气运又被乾坤袋 / 金丹抬高，
  三者一叠加，杀一只妖的补给期望反而比一层更高。所以心血掉率、灵力珠的掉率与单颗量、
  精英必掉量、Boss 转阶段单颗量**全部乘以 `0.82^(层−1)`**：一层不变（体感与从前一致），
  五层只剩约 45%。**气运在这条下降的基线上加成，抵消不了衰减本身**。
  灵石不在其列 —— 它另有 `planEconomy` 的整层配额锁着，与层数无关。
- **专属技能**（按 `空格`）：**舞剑流开局就自带**（近战没有突进贴不了身，基础冷却 15 秒）；
  飞剑 / 巨剑流仍是首杀精英自动获得（基础冷却 30 秒）。之后再斩精英即可三选一精进。
  飞剑流「万剑归宗」三柄并列、连绵十轮共 30 柄；巨剑流「天崩剑狱」巨剑自天而降、钉入地面；
  舞剑流「剑影三叠」按住空格蓄势、松手朝指针突进斩击，**突进距离随蓄势时长伸缩**，一按一放的手感全在分寸上。
  三者一律朝**鼠标指针**释放（鼠标没动过才退回最近瞄准方向 / 人物朝向）。
- **护盾分两种**：**常驻护盾**（太虚护盾 / 羽衣 / 灵力丹 / 地上的护盾）不设时限，
  只被受击逐层扣掉，可以一直囤着；**限时护盾**只有护体金光一家 ——
  结 2 层只维持 5 秒，到点整层散去。两者同在时先消耗限时的那份。
- **气血恒为整数**：血量单位是「半颗心」，小数伤害（精英余祸的 1.1 / 1.2）会在结算时取整，
  否则会出现「血条整条空、人却还活着」的假死相。
- **魔头房里的小怪不掉灵石**：尊者会按阶段**无限召唤**爪牙，若照常掉落，这一层就多出一个
  刷不完的口子，`planEconomy` 锁死的预算当场失效（连「贪心」那条预算外的额外产出口也一并封）。
  该房的灵石配额原封不动，留给尊者伏诛时**一次性发放** —— 总量不变，只是不再能刷。
- **魔头房一阶段有 45 秒软时限**：凝形结束后才开始计时，到点若还没打掉三分之一血，
  就强制转入二阶段（咆哮 + 清弹幕 + 外溢灵力，与血量转阶段同一套流程）。
  一阶段的爪牙是**无限召唤**的（每 280 帧一批），没有这条线，玩家可以干脆不打尊者、
  赖在召唤阶段刷爪牙 —— 而爪牙既掉灵力珠、又吃舞剑流「剑意不绝」的击杀返还冷却，
  会变成一个「我不想输就不会输」的龟缩洞。时限只压一阶段，
  血量提前转入二阶段的不会被它再推一次。
- **伤害数字**：普通命中是一枚清色小字；**暴击换成朱红大字**（2 倍点阵 + 八向黑描边 +
  命中环 + 出场白光 + 开头几帧抖动，末尾缀一个「!」），并补一记轻微震屏。
  持续伤害（尸毒 / 燃烧）不报数，全场数字上限 48 枚且**优先保暴击**，
  一次打一片时不至于糊满屏；挨得太近的两枚会自动横向推开，免得叠成一坨看不清数值。

## 技术实现

- 纯原生 JavaScript + Canvas 2D，无框架、无构建工具
- 内部渲染分辨率 480×320，像素级放大（`image-rendering: pixelated`）
- 自研像素绘制引擎（`src/px.js`）：像素图元 + 自动描边 + 确定性随机
- WebAudio 实时合成音效（无音频文件）
- 固定 60Hz 步进主循环，实体按 Y 轴排序渲染

### 列宽 / 行高设置的几个坑

每个 `tab_xxx()` 返回的 `widths` 是**大致能放几个字**，`style_tab()` 里会 ×8 换算成像素。
踩过的坑都写在 `style_tab()` 的注释里，改动前先看一眼：

1. `set_dimension_size` 的列宽单位是**像素**，不是字符数。直接传 `14`、`30` 这种字数，
   列会被压成十几像素宽，文字一个字一行地竖排，整张表就废了。
2. 对**已经有自定义列宽**的列再设 `size` 会被静默忽略（不报错、也不生效），
   必须先用 `is_clear: true` 清掉旧值。所以同步脚本每次都是「先 clear 再 set」，
   这样重复运行也不会被上一次的结果锁死。
3. `size` 要传**浮点数**，传整数同样不生效。
4. **行高**同理：默认 20px 装不下 wrap 之后的长文本（描述、概率、备注这些列会写成三四行），
   所以 `style_tab()` 会按最长的那一格估算行高。表末的「说明」行字数远多于数据行，
   单独估一次，否则会把上面几十行数据行一起撑到上限。

改完可以这样回读验证：

```python
call('get_dimension_size', {'sheet_id': sid, 'dimension_type': 'col', 'index': 0})
call('get_dimension_size', {'sheet_id': sid, 'dimension_type': 'row', 'index': 1})
```
